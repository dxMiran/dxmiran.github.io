SERVER SCRIPT
EXAMPLE 01

Ability cooldown

Place in ServerScriptService. Create a RemoteEvent named UseAbility in ReplicatedStorage.

local RS = game:GetService("ReplicatedStorage")\nlocal Players = game:GetService("Players")\nlocal event = RS:WaitForChild("UseAbility")\nlocal cooldowns = {}\nlocal COOLDOWN = 5\n\nevent.OnServerEvent:Connect(function(player)\n    local now = os.clock()\n    if cooldowns[player] and now - cooldowns[player] < COOLDOWN then return end\n    cooldowns[player] = now\n    print(player.Name .. " used their ability!")\n    -- Add your ability logic here.\nend)\n\nPlayers.PlayerRemoving:Connect(function(player)\n    cooldowns[player] = nil\nend)
The server tracks each player's last activation and ignores requests made before the five-second cooldown ends.
LOCAL SCRIPT
EXAMPLE 02

Dash input

Place in StarterPlayerScripts. The server should validate the request and apply movement.

local UIS = game:GetService("UserInputService")\nlocal RS = game:GetService("ReplicatedStorage")\nlocal dash = RS:WaitForChild("DashRequest")\n\nUIS.InputBegan:Connect(function(input, processed)\n    if processed then return end\n    if input.KeyCode == Enum.KeyCode.Q then\n        dash:FireServer()\n    end\nend)
Pressing Q requests a dash. Add server-side checks for cooldown, character state and allowed movement.
LOCAL SCRIPT
EXAMPLE 03

Combo counter UI

Place in a ScreenGui with a TextLabel named ComboLabel. Add a RemoteEvent named ComboUpdate in ReplicatedStorage.

local RS = game:GetService("ReplicatedStorage")\nlocal event = RS:WaitForChild("ComboUpdate")\nlocal label = script.Parent:WaitForChild("ComboLabel")\n\nevent.OnClientEvent:Connect(function(combo)\n    if combo > 1 then\n        label.Text = tostring(combo) .. " HIT COMBO"\n        label.Visible = true\n    else\n        label.Visible = false\n    end\nend)
The server sends the confirmed combo count; the client only displays it.
